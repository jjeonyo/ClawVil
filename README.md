## 빠른 시작

Node.js 18 이상만 있으면 된다. 설치할 패키지는 없다.

```bash
git clone https://github.com/jjeonyo/PokeAI.git
cd PokeAI
node server.js          # 브라우저에서 http://localhost:4848 열기
```

Claude Code 없이 먼저 구경하려면 데모 모드로 실행한다. 임시 폴더에 가짜 세션을 계속 써 넣는다.

```bash
node server.js --demo
```

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `--port` | `4848` | 서버 포트 |
| `--dir` | `~/.claude/projects` | 세션 기록 폴더. `CLAUDE_CONFIG_DIR`가 있으면 `$CLAUDE_CONFIG_DIR/projects` |
| `--demo` | 꺼짐 | 가짜 세션으로 보여주기 |

화면 조작: 드래그로 이동, 휠 또는 `＋` `－` 버튼으로 확대·축소, `⟳`로 전체 보기.

## 화면 읽는 법

### 층 = 프로젝트, 세션 = 그 층의 매장

![층 이동](docs/screens/floors.png)

- 왼쪽 **층별 안내**에서 층을 누르면 `▲ 4F` 엘리베이터 표시등이 뜨고 그 층으로 이동한다.
- 지금 기록이 쌓이는 층에는 초록불이 켜진다. 사흘 넘게 조용한 층은 "불 꺼진 지 오래된 층"으로 접힌다.
- `/clear`로 새 세션이 시작되면 같은 층의 새 세션으로 자동으로 따라간다. 지난 세션을 직접 누르면 자동 따라가기가 꺼진다.
- 층마다 풍경이 다르다: 초원, 해변, 황금 고원, 설원.

### 방 = 도구

| 방 | 이럴 때 간다 | 화면 변화 | Claude 작업 소품 |
| --- | --- | --- | --- |
| 📚 자료실 | `Read` `Grep` `Glob` | 책을 펴고 읽는다 | 동그란 안경 |
| 💻 개발실 | `Edit` `Write` | 모니터에 코드가 흐른다 | 안전모 |
| 🗄️ 서버실 | `Bash`, git | 랙 불빛이 빨라진다 | 헤드셋 |
| 🌐 정보검색실 | `WebSearch` `WebFetch`, MCP 도구 | 지구본이 돌고 안테나가 신호를 보낸다 | 안테나 머리띠 |
| 📝 회의실 | `TodoWrite`, 플랜 모드 | 게시판에 할 일 메모가 붙는다 | 베레모와 연필 |
| 🧑‍💻 내 자리 | `AskUserQuestion` | 내 책상까지 찾아와 묻는다 | |
| 🛗 엘리베이터 | `Agent`(`Task`) | 서브에이전트가 출퇴근한다 | |

### 말풍선과 표정

| 보이는 것 | 뜻 |
| --- | --- |
| 흰 말풍선 | 지금 쓰는 도구, 또는 Claude의 답변 |
| 보라 구름 말풍선 | 생각 요약 (`thinking`) |
| 빨간 말풍선 + 식은땀 | 도구 실패 |
| 노란 말풍선 | 질문, 또는 승인을 기다리는 것으로 보이는 상태 |
| 초록 말풍선 + 웃는 눈 | 서브에이전트의 결과 보고 |
| 주황 말풍선 + 전화기 | 서브에이전트를 부르는 중 |
| `?` | 20초 넘게 조용함 (고민 중) |
| `z z z` | 3분 넘게 쉬는 중 |

오른쪽 패널에는 사무실에 있는 캐릭터의 상태, 도구 사용 횟수, 시간순 활동 로그가 나온다.

## 등장인물

![캐릭터](docs/characters.png)

| 캐릭터 | 맡은 역할 |
| --- | --- |
| **모찌** — 별꽃 새싹이 난 코랄색 찹쌀떡 | Claude |
| **새싹이** — 탐험 모자와 돋보기 | Explore 서브에이전트 |
| **부엉이** — 둥근 안경과 설계도 | Plan 서브에이전트 |
| **토끼** — 파란 목도리 | 범용(general-purpose) 서브에이전트 |
| **병아리** — 작은 가방 | 그 밖의 서브에이전트 |
| **후드티 입은 사람** | 나 |
| **양 · 개구리 · 오리 · 나비** | 마을 주민 (쉼터 낮잠, 연못가 뜀뛰기, 연못 헤엄) |

서브에이전트는 일이 끝나면 Claude 옆으로 걸어와 결과를 보고하고 "👋 퇴근합니다!" 하고 엘리베이터로 사라진다. 보고하러 가다가 일을 하나 더 받으면 다시 일하러 돌아간다.

캐릭터와 마을 그림은 모두 이 프로젝트를 위해 캔버스 코드로 직접 그린 오리지널이며, 외부 이미지 파일을 쓰지 않는다.

## 동작 방식

1. Claude Code는 대화를 `~/.claude/projects/<프로젝트>/<세션>.jsonl`에 한 줄씩 기록한다.
2. `server.js`가 이 파일을 0.25초마다 이어서 읽고, 화면에 필요한 이벤트(도구 호출과 결과, 생각, 답변)만 추려 브라우저에 넘긴다.
3. 서브에이전트 기록(`<세션>/subagents/*.jsonl`, 예전 버전의 `agent-*.jsonl`)도 함께 읽어 각 캐릭터를 움직인다.
4. 처음 열 때는 최근 기록을 빠르게 재생해서 현재 상태(누가 어디서 무엇을 하는지)를 맞춘다.

- Claude Code의 훅이나 설정을 바꾸지 않는다. 기록 파일을 읽기만 한다.
- 서버는 `127.0.0.1`에만 열리고 다른 호스트 이름으로 들어온 요청은 거절한다.
- 외부로 나가는 요청은 웹 글꼴(Google Fonts)뿐이다. 세션 내용은 PC 밖으로 나가지 않는다.

## 알려진 한계

- **승인 대기는 추정이다.** 기록에는 권한 확인 창이 남지 않아서, 파일 수정 같은 도구가 7초 넘게 끝나지 않으면 승인을 기다리는 것으로 본다.
- **한 층에는 한 세션만 보인다.** 같은 프로젝트에서 세션 여러 개를 동시에 돌리면 가장 최근 세션을 따라간다. 다른 세션은 층별 안내에서 직접 고른다.
- **처음 열 때는 세션 끝부분 2MB만 읽는다.** 아주 긴 세션에서는 그보다 앞선 할 일 목록이나 진행 중인 서브에이전트가 빠질 수 있다.

## 파일 구조

```text
server.js            세션 목록 · jsonl 증분 읽기 API, 정적 파일 서버
demo.js              --demo 용 가짜 세션 작성기
public/
├── index.html       화면 틀
├── style.css        패널과 UI 스타일
├── app.js           기록 → 캐릭터 행동, 층 안내 · 사람 목록 · 활동 로그
├── world.js         지형, 방과 소품, 길찾기, 렌더링
├── critters.js      캐릭터 그리기
└── art.js           등각 좌표, 음영 블록, 스프라이트 캐시
docs/                README 이미지
```
